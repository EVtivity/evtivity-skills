# Contributing

Pull requests and discussions are welcome.

- Fix or extend a skill: edit `skills/<name>/`. Follow the rules in [AGENTS.md](AGENTS.md).
- New skill: open a discussion first. Describe what it does and when an agent should use it.
- Keep every fact traceable to the public EVtivity docs (https://www.evtivity.com/docs) or the public repository (https://github.com/EVtivity/evtivity-csms).
- Never include secrets, real hostnames or IP addresses, or personal data, in skills, examples or pull requests.
- Run the checks in AGENTS.md before you open a pull request. CI runs them too.
- Commit messages: Conventional Commits, one line, English.

Bugs in EVtivity itself belong in https://github.com/EVtivity/evtivity-csms/issues. Security issues follow the security policy of that repository, not a public issue.
